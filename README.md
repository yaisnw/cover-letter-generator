# Cover Letter Generator

Paste a job description, upload your resume as a PDF, and get a tailored cover letter generated by Google Gemini.

## Features

- Job description input (up to 5000 characters) that grows with its content
- PDF resume upload
- Generation through a Next.js Server Function that sends the description and resume to Gemini (`gemini-3.6-flash`)
- Inline error messages for a missing description, a missing or empty resume, and API failures
- One-click copy of the generated letter
- The job description and the last generated letter are saved in `localStorage`, so they survive a page refresh. The uploaded resume is not saved; upload it again after a refresh.

## Tech stack

- [Next.js](https://nextjs.org) 16 (App Router) with React 19 and TypeScript
- Tailwind CSS v4, with a custom color palette defined as theme tokens in `app/globals.css`
- [`@google/genai`](https://www.npmjs.com/package/@google/genai) for the Gemini API
- Jest and React Testing Library for tests

## Getting started

Requires Node.js 20 or later.

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create a `.env` file in the project root with your Gemini API key:

   ```
   GEMINI_API_KEY=your-key-here
   ```

   The key is read on the server only and is never sent to the browser.

3. Start the dev server:

   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000).

## Project structure

```
app/
  actions.ts                   Server Function that calls Gemini
  components/cover-letter-form.tsx   Client form: state, localStorage, copy button
  page.tsx                     Landing page (Server Component)
  layout.tsx                   Root layout and metadata
  error.tsx                    Error boundary fallback
  globals.css                  Tailwind import and theme tokens
__tests__/                     Jest tests
__mocks__/@google/genai.ts     Manual mock of the Gemini SDK for tests
```

## Testing

```bash
npm test
```

Tests cover the server action's validation and error handling (with the Gemini SDK mocked, so no API key or network is needed), the form's persistence and result display, and the error boundary.

## CI

GitHub Actions (`.github/workflows/nextjs.yml`) runs `npm ci`, `npm run build` and `npm test` on pushes and pull requests to `main`.
